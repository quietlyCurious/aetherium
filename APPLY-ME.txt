What's new: screen sizes
------------------------
Every screen is now one of three fixed sizes, set beside "About" in the
Page's General details:

    Tile   220 x 140   a number or two, at a glance
    Card   360 x 280   one asset's summary
    Page   fills       a whole screen (what every existing screen is)

* The canvas frames a Tile or a Card at its real size while you design it,
  so you're not laying out a 220-pixel tile in a 1200-pixel space. A device
  preview still wins if you pick one. Launch frames it the same way.
* The saved-screens list badges anything that isn't a Page, since a type
  now usually has more than one screen.
* One screen is one size for now, as we agreed: a turbine's Tile and its
  Card are two saved screens. If that gets tedious, the breakpoint tiers
  the canvas already has are where a single screen with three layouts would
  go — screenSizes.js stays the vocabulary either way.

A repeater now asks for a size rather than typed-in item dimensions
------------------------------------------------------------------
"Item size: Card" means "each type's Card screen", and the item box comes
from the size. The lookup is type + size, and where nothing is built yet it
falls back to **the card Visualization already draws for that type** rather
than a placeholder — the same AssetCard component the Operator's related-
asset views use, titled with the asset's own name. So a repeater over a
mixed fleet is useful on the day you build it, and each screen you design
replaces one default. The details panel says which types are on a generated
card. A screen smaller than its box is centred, not stretched.

Two things I fixed while I was in there
---------------------------------------
* Launching a plain screen whose only content was a repeater showed
  "That set belongs to the wind model" — the runtime had no page context to
  tell it which model to load. It now takes the model from the repeater's
  asset set (modelForScreen).
* Five tiles in a tall container came out as one row at the top and one at
  the bottom; wrapped rows now pack at the top.
